# Ravi Kumar — Portfolio

Personal portfolio of **Ravi Kumar**, Senior Frontend / Full-Stack Engineer and Founder of [Her Aviation Era](https://heraviationera.com).

![Next.js](https://img.shields.io/badge/Next.js_16-000?logo=nextdotjs) ![React](https://img.shields.io/badge/React_19-087EA4?logo=react&logoColor=fff) ![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?logo=typescript&logoColor=fff) ![Tailwind CSS](https://img.shields.io/badge/Tailwind_4-06B6D4?logo=tailwindcss&logoColor=fff) ![shadcn/ui](https://img.shields.io/badge/shadcn%2Fui-000)

## Stack

- **Next.js 16** (App Router) with `output: "export"` — fully static, hostable anywhere
- **React 19 · TypeScript · Tailwind CSS 4 · shadcn/ui**
- **Framer Motion** for restrained scroll reveals (respects `prefers-reduced-motion`)
- **MDX** articles, **next-themes** light/dark mode, build-time GitHub contribution graph

## Develop

```bash
npm install
npm run dev      # local dev
npm run build    # static export to out/
```

## Edit content

All copy lives in one typed file: [`content/profile.ts`](content/profile.ts) — hero, projects, experience, skills, articles metadata. Articles are MDX under `app/articles/`. Replace the SVG placeholders in `public/images/` with real screenshots, and `public/resume.pdf` with the latest resume.
